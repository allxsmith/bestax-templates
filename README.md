# bestax templates

Free Bulma templates from aldi's [awesome-bulma-templates](https://github.com/aldi/awesome-bulma-templates), rebuilt with [bestax](https://bestax.io), the React component library for Bulma. Each folder is a complete Vite, React and TypeScript project that runs on its own and credits the template it was ported from.

Browse them with screenshots and filters at [bestax.io/templates](https://bestax.io/templates).

## Templates

### Login

A sign-in page on a frosted glass card, with social login buttons and a language picker.

- [Open in StackBlitz](https://stackblitz.com/github/allxsmith/bestax-templates/tree/main/login?file=src/App.tsx)
- Ported from [aldi/bulma-login-template](https://github.com/aldi/bulma-login-template) by [aldi](https://github.com/aldi), at commit `4f6c099`
- License: MIT, the upstream's, in [LICENSE](login/LICENSE)

## Run one

Each folder is its own project:

```bash
cd <folder>
npm install
npm run dev
```
